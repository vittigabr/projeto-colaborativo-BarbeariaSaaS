# Barbearia SaaS — Documentação de Requisitos

Esta documentação apresenta a visão geral, regras de negócio, requisitos funcionais e não funcionais, organização de pastas, proposta de banco de dados normalizado e telas do sistema.

**Projeto GitHub:** https://github.com/vittigabr/projeto-colaborativo-BarbeariaSaaS

> **Nota sobre o estado do projeto:** a interface voltada ao cliente foi desenvolvida parcialmente. As áreas de funcionário, administrador e integração completa com back-end/MySQL são descritas como requisitos ou propostas até que estejam implementadas e validadas no código.

Importe ou sincronize a pasta `docs` no GitBook. As imagens das telas devem ser adicionadas à pasta `docs/imagens` e os caminhos indicados no documento de telas devem ser atualizados de acordo com os nomes dos arquivos.
