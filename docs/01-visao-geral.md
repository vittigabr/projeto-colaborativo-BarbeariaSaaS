# 1. Visão Geral

## 1.1 Apresentação

A **Barbearia SaaS** é um sistema web colaborativo que tem como finalidade facilitar a divulgação dos serviços de uma barbearia e organizar o processo de agendamento. A aplicação propõe reunir em um único ambiente as informações sobre clientes, profissionais, serviços e horários.

## 1.2 Problema

O controle manual ou descentralizado de agendamentos pode provocar conflitos de horários, dificuldade para consultar a agenda e retrabalho na comunicação com os clientes. A proposta do sistema é centralizar essas informações e tornar o processo mais claro.

## 1.3 Objetivo geral

Desenvolver uma aplicação web responsiva para apresentar os serviços da barbearia e apoiar o gerenciamento dos agendamentos, oferecendo áreas específicas para cliente, funcionário e administrador.

## 1.4 Objetivos específicos

- Permitir que clientes conheçam os serviços disponíveis.
- Oferecer cadastro e autenticação de usuários.
- Permitir a solicitação e consulta de agendamentos.
- Organizar a agenda dos profissionais.
- Permitir que o administrador gerencie serviços e funcionários.
- Armazenar os dados de forma estruturada em banco de dados.
- Facilitar manutenção e evolução por meio de código organizado e versionamento.

## 1.5 Público-alvo

- **Clientes:** pessoas que desejam consultar serviços e marcar horários.
- **Funcionários/barbeiros:** profissionais que precisam consultar sua agenda.
- **Administrador/proprietário:** responsável por gerenciar serviços, equipe e agenda.

## 1.6 Tecnologias

- HTML: estrutura das páginas.
- CSS: apresentação visual e responsividade.
- JavaScript: interatividade no front-end.
- MySQL: banco de dados relacional planejado.
- Git e GitHub: controle de versão e colaboração.
- Back-end/API: camada necessária para autenticação, regras de negócio e acesso seguro ao banco; tecnologia específica deve ser registrada quando definida pela equipe.
